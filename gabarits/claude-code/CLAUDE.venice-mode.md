
## Mode Venice (sur demande seulement)
Par défaut, travaille normalement. Quand l'utilisateur dit « utilise venice », « passe sur venice », « mode venice » ou tape /venice, bascule pour le reste de la session : pour toute création ou modification de code, appelle l'outil `mcp__deepseek__deepseek_coder` (DeepSeek V4.1 Flash Uncensored via le pont Venice : gratuit, ~500k de contexte, non censuré) au lieu d'écrire toi-même avec Edit ou Write. Tu explores, tu choisis les fichiers, tu relis (`git diff`) ; donne-lui une consigne précise, TOUS les fichiers utiles (`fichiers`) et une commande `test` quand il y en a une. Pour lire ou analyser beaucoup de code sans modifier, `mcp__deepseek__deepseek_demander`. « arrête venice » ou « mode normal » fait revenir au fonctionnement habituel. Si l'outil échoue (pont injoignable), dis-le et écris le code toi-même.
