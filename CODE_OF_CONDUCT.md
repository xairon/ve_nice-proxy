# Code de conduite

Soyez courtois et factuel. Critiquez le code et les idées, pas les personnes. Aucun harcèlement, aucune attaque personnelle, aucune publication de données privées d'autrui (cookies, clés, adresses).
Les mainteneurs peuvent modérer ou fermer tout échange qui ne respecte pas ces règles. Signalement : avis de sécurité privé ou message au mainteneur via son profil GitHub.
